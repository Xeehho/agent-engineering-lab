# 学习笔记本与错题集

笔记本用于记录“我在哪里卡住、当时怎样理解、后来如何验证”。它是个人复习工具，所有内容保存在当前浏览器，不会自动上传、发给老师或改变正式考试成绩。网页与单文件离线课堂均可使用，无需安装后端或接入模型。

## 从一次练习开始

以第一课的 JSON 实验为例：

1. 在“运行前预测”写下预期，再运行代码。
2. 在“观察与证据边界”写下实际输出，例如：`JSON.parse("42")` 得到数字42，解析成功不代表得到业务对象。
3. 点击下方“整理实验为笔记”或“标为薄弱点”。实验观察作为正文，预测、观察与最近一次实际执行的代码/输出作为关联快照。
4. 补充自己的解释、标签（如 `JSON, 运行时校验`）、状态与回顾日期。每次输入自动保存，底部显示实际保存状态。
5. 点击顶部“笔记本”，以后直接按关键词、阶段或模块找回来。点击“回到知识点”能返回对应课程，进阶折叠区也会打开。

讲义各知识点、随堂题、选择题、脑图和工程架构都有相同入口。随堂题创建笔记时带上自己的作答；选择题带上创建时的选择；脑图与架构记录对应材料。新建通用笔记归属当前选中的课程；只筛阶段时归属该阶段的当前课或第一课，编辑框顶部显示归属。

已整理的笔记是独立快照：修改原来的实验观察或作答，不会改掉它。实验只保留最近一次运行，输出最多8000字符，关联快照最多18000字符；超长实验快照会注明截断。需要完整执行档案时，请另外保存代码和日志。旧版没有保存过的输出不会凭空补齐。

## 四种查看方式

|入口|可以看到什么|适合什么时候用|
|---|---|---|
|知识点笔记|自己整理的解释、标签、薄弱状态与回顾日期|系统整理，回看自己的理解|
|原始记录|本课原有个人笔记、实验预测/观察及最近运行快照|继续原记录，或整理成独立笔记|
|错题集|已经提交的选择题错题、题面快照、订正和作答历史|查找误解，重新作答|
|到期回顾|已到设定日期的笔记与错题|集中复习，不必重新翻完整课程|

四种视图都能组合使用阶段、课程、内容模块、复习状态与关键词筛选。关键词包含标题、正文、标签、来源与课程名。“仅看本课”缩小范围，“清除筛选”恢复全课程。顶部数字提示到期条数；统计卡显示全课程数量，列表说明显示当前筛选数量。大量记录先显示80条，导出包含全部匹配结果。

对笔记选择“仍需巩固”会标为薄弱点、安排明天再看；“已解释清楚”会标为已回顾、安排三天后再看。日期可以在编辑框自行修改或清空。这是便于操作的提醒安排，不是自动判断记忆程度的算法。

## 错题如何进入、如何订正

- 完成入门选择题并点击提交，才记录本次自测；已答的进阶题也会参与收错，未答进阶题不算错。改选但未提交不会增加错题。
- 同一题面与同一组答案重复点击提交，不重复计次。后来改对也保留错题。新版题面保留为独立快照，旧错题仍按旧题面复习。
- 展开“写订正并重新作答”，用自己的话写：原先误解是什么、正确判断是什么、怎样用反例验证。再选择答案，提交这道题的复习。
- 选对且填写订正说明才标为已订正；只写说明或只选对都不够。再次选错会恢复待订正。保留累计错选、最近错选及最近30次作答历史。
- 错题卡中可以查看参考答案和完整讲评、回到课堂、创建关联笔记、调整回顾日期或导出本题。

开放题需要人工理解答案；故意失败的实验也可能说明理解正确。因此这些记录不自动判错，用“标为薄弱点”自行整理。笔记复习与错题复习不增加课堂四项活动进度，不产生教师评分或“已掌握”认证。

## 导出与恢复

|操作|文件内容|用途|
|---|---|---|
|导出本条 / 本题|单条笔记、快照或错题和订正的 Markdown|个人知识库、给老师讨论|
|导出当前筛选|所有匹配记录的 Markdown，包含完整正文|按模块整理、集中打印或分享|
|备份全部记录 JSON|全部课程作答、代码、观察、运行快照、笔记本与错题历史|更换浏览器/网址/设备、完整恢复|
|导出课堂作答 Markdown|当前课开放作答、实验、原笔记及笔记本/错题|交给老师或教学助手评阅|

Markdown用于阅读，不能当作完整恢复文件；恢复请导入JSON。导入先校验，再确认替换当前浏览器的全部记录，**不会自动合并两个版本**。导入前先导出当前完整JSON。文件上限10MB，兼容v1单课、v2整书，当前备份版本为v3。每课最多150条知识点笔记与200个错题版本，正文最多12000字符。

浏览器、设备和网站来源之间不自动同步。例如本地 `127.0.0.1` 与线上域名的记录各自独立；清缓存或关闭隐私窗口也可能丢失。下载文件中包含自己的作答和笔记，分享前自行检查，不建议提交到公开仓库。

## 保存异常时怎么办

正常编辑显示“已保存到本机”。若空间不足，页面会明确提示，本页暂存仍可导出。清理自己不需要的笔记前先备份，再尝试保存。

如果另一标签页修改了同一份记录，当前页会暂停覆盖并显示提示。可以先分别“导出本页完整记录”和“下载浏览器原记录”，保留两个版本，再选择“载入浏览器最新记录”。载入会丢弃本页尚未保存的暂存，不做自动合并。

如果原记录损坏或版本无法识别，页面不会用空记录覆盖它。先下载浏览器原记录，再修复或导入有效备份；不要清空缓存来排错。
