## 验收证据

- 协议修订、SDK 与运行环境明确：待提交证据
- 真实发现、调用、错误与取消可复现，网页模拟不计互通：待提交证据
- 身份与租户权限不来自模型参数：待提交证据
- 日志通道、返回上限、服务来源与凭证作用域可解释：待提交证据
