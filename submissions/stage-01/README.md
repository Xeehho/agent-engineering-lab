# 第一阶段交卷材料

在自己的学习分支提交，建议分支名learn/stage-01。

- diagnostic.md：起点诊断。
- answers.md：Q1–Q12自己的解释。
- design.md：数据流、错误流、超时与流式状态。
- evidence.md：检查命令、commit、实际结果、Mock/live范围。
- retrospective.md：至少一个本人定位问题的过程，以及AI协助范围。

不要只贴“测试已通过”。命令输出可节选关键部分并附可复现步骤；密钥、私人数据不提交。

## evidence.md建议格式

~~~text
commit:
运行环境:
check命令及结果:
公开练习结果:
新增边界验证:
流式成功/失败/取消:
Mock验证范围:
真实模型验证范围:
我本人核对了:
尚未验证:
~~~

## retrospective.md建议格式

~~~text
我预期的行为:
实际发生的行为:
我观察到的证据:
根因:
修复与回归:
AI提供了:
我亲自判断了:
我仍解释不清的部分:
~~~

完成后在聊天说：“第一阶段交卷，分支xxx，commit xxx”。老师会review并安排考试。
