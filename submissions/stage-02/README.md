# 阶段 02 提交模板

个人原始作答请放 submissions/private/ 或另行提供，不默认加入未来公开教材。

## 提交身份

- 分支 / commit：
- 环境 / 运行命令：
- 服务、数据库、模型和版本：

## 验收证据

- 已知工具白名单、参数/结果验证和调用关联：待提交证据
- 最大轮次、工具次数、总期限、取消和停滞处理：待提交证据
- 读取/草稿/写入权限分离，具体确认与持久幂等：待提交证据
- 未知工具、注入、重复写入和预算耗尽均有拒绝路径：待提交证据

## 失败复盘

复现 → 假设 → 观测 → 定位 → 最小修复 → 回归 → 未验证项。

- Mock / 真实模型 / 真实服务 / 生产验证分别说明：
- 请求老师出题：
