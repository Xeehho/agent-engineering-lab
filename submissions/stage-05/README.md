# 阶段 05 提交模板

- 分支 / commit：
- 环境 / 运行命令：

## 验收证据

- 采集、清洗、切分、删除与索引血缘可追踪：待提交证据
- 关键词/向量/混合基线，模型与索引版本可复现：待提交证据
- 重排、来源支持、冲突/过期/无答案分别处理：待提交证据
- 检索/回答/引用/拒答分层评测，测试集与开发集隔离：待提交证据
