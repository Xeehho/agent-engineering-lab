## 验收证据

- 需求、实现、验证与演示逐项对应：待提交证据
- 本人解释关键路径并处理新需求与陌生故障：待提交证据
- 个人/课程经历真实标注，指标有样本/基线/环境：待提交证据
- 目标 JD 与能力证据映射，缺口补学，不承诺薪资或录用：待提交证据
