## 实验：永不结束的提议如何被截止？

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
let calls = 0;
const limit = 3;
while (calls < limit) {
  const decision = {tool:"searchDocs"}; // 固定假决策
  calls++;
  console.log("执行", calls, decision.tool);
}
console.log("停止原因: TOOL_BUDGET_EXCEEDED");
~~~

观察方向：只能执行三次。改为每轮两个工具，检查计数应放在每次执行还是每轮外侧。

提示：计数单位要与实际约束一致。
