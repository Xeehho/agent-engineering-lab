## 实验：await 表达的是等待点

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
const events = [];
async function handle(name) {
  events.push(name + ":start");
  await Promise.resolve();
  events.push(name + ":resume");
}
await Promise.all([handle("A"),handle("B")]);
console.log(events);
~~~

观察方向：先出现两个 start，再出现两个 resume；这不是 Python 运行，也没有 CPU 并行。

提示：区分任务可交错推进和同时使用多个 CPU 核心。
