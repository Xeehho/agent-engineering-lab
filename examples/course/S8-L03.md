## 实验：简历指标是否有证据？

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
const bullets=[
 {text:"课程项目：完成工单分诊",source:"commit + 本地用例"},
 {text:"生产准确率 99.9%",source:null}
];
for(const b of bullets) console.log(b.text,b.source?"可继续核验":"缺依据，不能这样宣称");
~~~

观察方向：第二条没有依据；第一条也需说明个人贡献和验证范围。

提示：把课程项目与生产经验分别描述。
