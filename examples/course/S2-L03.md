## 实验：同一个意图重试两次

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
const results = new Map();
let created = 0;
function create(key) {
  if (!results.has(key)) results.set(key, {id:++created});
  return results.get(key);
}
console.log(create("intent-42"), create("intent-42"), {created});
console.log("Map 只演示单进程去重，不提供分布式原子性或持久化");
~~~

观察方向：同键只创建一次；刷新进程后 Map 丢失，生产方案还需要数据库约束与事务。

提示：观察键是否跨重试保持稳定。
