## 实验：相同文字不等于相同可见证据

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
const chunks = [
 {id:"a",tenant:"A",version:2,text:"排障步骤"},
 {id:"b",tenant:"B",version:2,text:"排障步骤"},
 {id:"c",tenant:"A",version:1,text:"旧步骤"}
];
console.log(chunks.filter(c => c.tenant === "A" && c.version === 2));
~~~

观察方向：只有 A 当前版本可见；这只是数组过滤，还需在真实检索、缓存和引用中保持同一规则。

提示：检索前后的访问边界都要核查。
