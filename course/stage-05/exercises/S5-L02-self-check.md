# S5-L02 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 余弦相似度 0.9 表示？

- A. 自动拥有访问权限
- B. 在所用表示与度量下较相近，不等于正确概率
- C. 答案有 90% 正确率
- D. 必然是最新文档

公开解析：B。分数含义来自表示和任务验证，不能扩大解释。

## Q2 错误码精确检索常应保留哪条基线？

- A. 关键词/精确匹配
- B. 只随机采样
- C. 仅按文档长度
- D. 只按上传时间

公开解析：A。不同查询类型需要不同召回手段。

## Q3 更换 embedding 模型后应该？

- A. 无条件复用旧向量
- B. 只改 UI 名称
- C. 旧评测永远有效
- D. 核查维度、语义空间兼容性与索引重建

公开解析：D。索引数据与表示版本必须一致并重新验证。
