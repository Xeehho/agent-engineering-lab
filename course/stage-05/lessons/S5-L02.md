# S5-L02 找相近文字，与判断事实是两件事

## 先说我们要解决什么问题

用户搜“怎么退款”，文档写“退货后原路返还”。关键词可能漏掉；但语义相近的另一份过期文档也可能排很前。检索怎样兼顾这两类线索？

## 先把概念讲清楚

Embedding把文本转换成一组数字，称为向量；相似度衡量向量在选定计算方式下有多接近。它不是事实正确概率，也不是权限。关键词检索擅长精确编号和词语；向量检索有助于找到不同措辞。混合检索把不同结果组合，不能直接随意相加不同尺度的分数。

下面的向量由人手写，只演示点积：对应数字相乘再相加。真实embedding由指定模型产生，维度、归一化、距离度量和索引版本必须配套。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|query / vector|课堂二维数组，不是真实embedding输出|
|dot|课堂点积函数；这里不做余弦归一化|
|score|本例点积分数，没有“置信概率”含义|
|sort|JavaScript排序；相似度排序之后仍需权限、时效与证据判断|

## 先读这个最小例子

网页“动手实验”运行相同代码。先找输入、检查与输出；assert 是课堂提供的检查函数，不是模型能力。

~~~js
const query = [1, 0];
const docs = [
  { id: "退款说明", vector: [0.9, 0.1] },
  { id: "登录说明", vector: [0.1, 0.9] },
];
function dot(a, b) {
  return a.reduce((sum, value, index) => sum + value * b[index], 0);
}
const ranked = docs
  .map((doc) => ({ id: doc.id, score: dot(query, doc.vector) }))
  .sort((a, b) => b.score - a.score);
console.log(ranked[0].id, ranked[0].score);
assert.equal(ranked[0].id, "退款说明");
~~~
## 运行结果与逐步解释

~~~text
退款说明 0.9
~~~

查询沿第一维，退款说明第一维0.9，登录说明0.1，所以前者排第一。数字是我们设计的，不证明真实模型懂退款。混合检索可用各清单名次融合，例如RRF按1/(常数+名次)累计，避免把BM25与向量原始分数当同一单位；选哪种融合仍需同集评测。

## 1. 为什么关键词与语义各有用处

用户问“款项多久退回”，文档写“退款到账时效”。语义表示可能联系它们；而工单编号 T-42、错误码 E_CONN_RESET 需要精确匹配。纯向量与纯关键词都有失败场景，先建立能解释的关键词基线，再比较混合是否值得。

Embedding 把输入映射成固定维向量，训练目标决定哪些相似性被保留。维度更大不自动更好；模型、版本、归一化、语言、输入长度与 query/document 前缀都影响结果。更换模型后，旧文档向量通常需要重建，不能把不同空间的向量直接比较。

## 代码阅读：相似度、排名和融合分别计算

### 先手算一个余弦值

cosineSimilarity 输入两个同维非零向量。点积是对应项相乘再相加，长度是平方和开根号，最后用点积除以两长度的乘积。

查询 [1,0] 与文档 [0.8,0.2] 的点积为0.8，文档长度约0.825，所以余弦约0.970；与 [0,1] 的点积为0，余弦为0。0.970是几何相似度，不能解释成“答案正确概率97%”。

### 把长链拆成三份产物

词项基线先计算每篇文档命中了几个查询词，再排序成 lexicalRanking。向量基线先计算余弦，再排序成 vectorRanking。RRF 输入的是这两份有序ID列表，不是原始词项分数和余弦分数。

|文档|关键词排名|向量排名|融合结果|
|---|---|---|---|
|refund|1|1|最靠前|
|shipping|2|2|其次|
|error|未命中|3|仍可作为融合候选|

每一路第r名贡献1/(60+r)，从1开始计排名。相同文档来自两路时贡献相加，同一路重复ID先拒绝，避免重复加分。

### 实验与真实 embedding 的距离

二维坐标是题目手填的，测试只验证公式与排序管道。真实接入要替换向量来源，锁定模型、维度、版本、预处理与索引，再用相关性标注集比较召回。不能让聊天模型随口生成几个数字充当已验证的语义表示。

### 带提示的练习

先手算平行与垂直向量。再构造一个模长很大、方向较差的文档，比较点积与余弦。最后保持同一评测集，只新增混合检索，记录提升与退步；不要同时换模型和切块后宣称收益来自RRF。

## 2. 计算相似度并融合排名

### 完整实操文件：S5-L02.mjs

~~~js file=S5-L02.mjs
import assert from "node:assert/strict";

// 本课向量来自题目，不是 embedding 模型。先读公式，再读排名与融合。
function cosineSimilarity(leftVector, rightVector) {
  const sameDimension =
    leftVector.length > 0 && leftVector.length === rightVector.length;
  const allFinite = [...leftVector, ...rightVector].every(Number.isFinite);
  if (!sameDimension || !allFinite) {
    throw new Error("INVALID_VECTOR");
  }

  let dotProduct = 0;
  let leftSquaredLength = 0;
  let rightSquaredLength = 0;
  for (let index = 0; index < leftVector.length; index += 1) {
    dotProduct += leftVector[index] * rightVector[index];
    leftSquaredLength += leftVector[index] ** 2;
    rightSquaredLength += rightVector[index] ** 2;
  }
  const denominator = Math.sqrt(leftSquaredLength) * Math.sqrt(rightSquaredLength);
  if (denominator === 0) {
    throw new Error("ZERO_VECTOR");
  }
  return dotProduct / denominator;
}

const fixtureDocuments = [
  { id: "refund", words: ["refund", "arrival"], vector: [1, 0] },
  { id: "error", words: ["E_CONN_RESET", "retry"], vector: [0, 1] },
  { id: "shipping", words: ["shipping", "arrival"], vector: [0.8, 0.2] },
];

function sortByScore(scoredDocuments) {
  return scoredDocuments.sort((left, right) => {
    return right.score - left.score || left.id.localeCompare(right.id);
  });
}

const queryTerms = ["refund", "arrival"];
const keywordScores = fixtureDocuments.map((document) => ({
  id: document.id,
  score: queryTerms.filter((term) => document.words.includes(term)).length,
}));
const lexicalRanking = sortByScore(
  keywordScores.filter((document) => document.score > 0),
).map((document) => document.id);

const vectorScores = fixtureDocuments.map((document) => ({
  id: document.id,
  score: cosineSimilarity([1, 0], document.vector),
}));
const vectorRanking = sortByScore(vectorScores).map((document) => document.id);

// 接收排名而非原始分数，每一路同一文档只能贡献一次。
function reciprocalRankFusion(rankings, rankConstant = 60) {
  const fusedScores = new Map();
  for (const ranking of rankings) {
    if (new Set(ranking).size !== ranking.length) {
      throw new Error("DUPLICATE_RANK");
    }
    ranking.forEach((documentId, zeroBasedIndex) => {
      const rank = zeroBasedIndex + 1;
      const previousScore = fusedScores.get(documentId) ?? 0;
      fusedScores.set(documentId, previousScore + 1 / (rankConstant + rank));
    });
  }
  const scoredDocuments = [...fusedScores].map(([id, score]) => ({ id, score }));
  return sortByScore(scoredDocuments).map((document) => document.id);
}

assert.equal(cosineSimilarity([1, 0], [1, 0]), 1);
assert.equal(cosineSimilarity([1, 0], [0, 1]), 0);
assert.throws(() => cosineSimilarity([0, 0], [1, 0]), /ZERO/);
assert.throws(() => cosineSimilarity([1], [1, 2]), /INVALID/);
assert.deepEqual(lexicalRanking, ["refund", "shipping"]);
assert.deepEqual(reciprocalRankFusion([lexicalRanking, vectorRanking]), [
  "refund",
  "shipping",
  "error",
]);
assert.deepEqual(
  reciprocalRankFusion([
    ["a", "b"],
    ["b", "a"],
  ]),
  ["a", "b"],
);
console.log("cosine checks + lexical ranking + reciprocal-rank fusion: passed");
console.log("top=refund; vectors synthetic; no trained embedding model executed");
~~~
~~~text expect=S5-L02.mjs
cosine checks + lexical ranking + reciprocal-rank fusion: passed
top=refund; vectors synthetic; no trained embedding model executed
~~~

**选做本地验证：**运行 npm run tutorial -- S5-L02。cosine 是点积除以两向量长度，零向量没有定义。不同维度直接拒绝，比悄悄截断可靠。RRF 对排名求 1/(k+rank) 后累加，避免直接相加两个不可比较的原始分数；它仍有候选数、k 与重复结果处理等参数。

## 3. 从课堂数值走向真实 embedding

下一步选择一个支持目标语言和部署条件的 embedding 模型，锁定名称、修订、维度与预处理，按其官方模型卡使用 encode 或服务接口。先用“退款/退回款项”“订单/订阅”“错误码/相近文本”等成对样本看排序，再建人工相关性标注。

不要根据本例的二维坐标解释真实模型某一维是“退款程度”。训练得到的维度通常没有这种单轴语义。也不要用聊天模型输出随机数字假装 embedding。远程接口需管理费用、限流、批量、失败重试与敏感数据出境范围；本课程默认不替你触发付费调用。

实际接入接口应返回 modelVersion、dimension 与向量数组，拒绝非有限数和维度不一致。索引写入同时保存块版本与 embedding 版本。重建采用新索引准备、对照验收、切换和可回滚引用。

## 4. 向量数据库解决什么

少量向量可以精确扫描；更多数据可能采用 ANN 索引，以一定召回损失换速度和内存。TopK 是“从候选里取几条”，不等于相关性保证。过滤是在搜索前、搜索中还是搜索后执行，会影响授权、候选数量和召回。

关键词侧可使用 BM25 等方法：同时考虑词频、文档频率和长度。实验只用词项重合计数，不能声称实现 BM25。中文需要分词、字粒度或适合语言的检索器，代码和编号还需要精确字段。

## 故障练习与项目迁移

把未归一化点积当 cosine，构造“大模长但方向差”的错误排序。把不同模型维度混入索引，验证立即拒绝。让两路排名重复同一块，检查融合前去重规则。

项目练习：保留关键词基线，接入一个实际 embedding 实现，提交固定数据集上的 Recall@K、延迟和索引版本。若只完成合成向量实验，如实标注尚未验证真实语义召回。

## 单页速记

- 表示模型决定向量含义，相似度公式不提供语义质量。
