## 1. 理解向量表示的作用与边界

Embedding 把文本映射为可比较的数值表示，用于语义检索等任务。向量相似不等于事实一致，否定、时间、产品版本和权限可能决定答案能否使用。相似度分数与模型、归一化和距离度量相关，不是可直接解释为答案正确概率的置信度。

## 2. 建立关键词与语义基线

错误码 E4017、函数名和工单编号可能适合精确或词法匹配，表述差异较大的问题可能从语义召回受益。混合检索融合不同候选，需要处理分数不可直接比较的问题，例如按排序做融合。先分别记录每种召回的覆盖，再决定融合规则，不能只堆技术名词。

## 3. 分开测试算法与基础设施

小数组余弦演示能说明计算，不证明大规模索引的性能或真实 embedding 质量。真实练习要选定 embedding 模型、维度、索引版本、距离设置与重建策略，使用固定标注查询测 Recall@k 与延迟。换 embedding 模型通常需要兼容性检查和重建索引。

## 实验：相似度不是正确率

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
function cosine(a,b) {
 const dot=a.reduce((sum,x,i)=>sum+x*b[i],0);
 const norm=Math.hypot(...a)*Math.hypot(...b);
 return norm === 0 ? 0 : dot/norm;
}
console.log(cosine([1,0],[0.8,0.2]));
console.log(cosine([1,0],[0,1]));
console.log("人工二维向量，不是真实 embedding 或正确概率");
~~~

观察方向：第一个更相似，第二个正交；数值不能解释为工单答案正确率。

提示：这里没有语言模型，也没有语义标签。
