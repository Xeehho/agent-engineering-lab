# S7-L04 把服务商响应转换成应用自己的结果

## 先说我们要解决什么问题

应用里的循环希望拿到type=final或tools，但真实模型服务可能用不同字段表示文本、工具、拒绝和截断。直接把外部对象散落到业务代码，会让换服务或升级接口很困难。

## 先把概念讲清楚

适配器负责把外部接口转换成应用内部契约。先读采用的服务商与SDK版本文档，分清返回成功、内容完整、工具提议、拒绝和用量未知等情况。结构化输出可帮助约束形状，仍不能证明业务内容正确。

真实接入是需要授权凭证与可能产生费用的进阶验证。本网页不请求任何模型。下面故意采用自定义fakeProvider格式，避免把课堂字段误认成某家SDK标准。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|fakeProvider / outputText / stop|本课人为构造的外部格式，不属于任何服务商API|
|type / text|本课应用内部结果格式，供S2-L02循环读取|
|normalize|课堂适配函数，将外部终态映射成内部结果|
|truncated|本课截断标签，不是服务商通用字段值|

## 先读这个最小例子

网页“动手实验”运行相同代码。先找输入、检查与输出；assert 是课堂提供的检查函数，不是模型能力。

~~~js
function normalize(response) {
  if (response.stop === "truncated") throw new Error("内容不完整");
  if (response.stop !== "complete") throw new Error("未知结束原因");
  if (typeof response.outputText !== "string" || !response.outputText.trim()) {
    throw new Error("缺少非空文本");
  }
  return { type: "final", text: response.outputText };
}
const fakeProvider = { stop: "complete", outputText: "回复草稿" };
console.log(normalize(fakeProvider).text);
assert.throws(() => normalize({ stop: "truncated", outputText: "半句" }), /不完整/);
assert.throws(() => normalize({ stop: "complete", outputText: " " }), /非空文本/);
~~~

回复草稿
~~~

完整响应转换成内部final；截断响应即使带有文本也拒绝作为完成结果。这是适配原则示例，没有验证任何真实服务。进阶接入时保留脱敏请求、模型/SDK/Prompt版本、结束原因、时间、usage及失败案例，凭证只能放服务端配置，不能写进HTML或提交。

本课只处理文本final，因此还检查trim后的文本非空，避免把空串和空白当作完成答案。真实服务可能返回工具提议或其他内容类型，那些需要先按类型转换，不能无差别套用这条文本条件。

## 1. 内部契约不要直接等于一家 SDK

应用希望拿到 text、usage、providerRequestId、模型版本和停止原因；不同服务商有不同字段、工具调用与流事件。适配器将外部协议转成内部契约，业务代码不应到处读取 provider.output[0]。

HTTP 200 后仍要验证 JSON、响应状态与内容形状。拒答、未完成、空文本、工具调用与完整文本是不同结果。此课只支持已完成的文本响应，其他形态显式拒绝，后续扩展时新增测试。

## 代码阅读：适配器怎样把外部协议收敛

### 先建立输入输出地图

generateTextWithAdapter输入固定服务地址、模型名、文本、信号和显式授权。输出统一为text、usage、providerRequestId和scope。业务层依赖这个内部结果，而不是到处读取服务商的output数组。

课堂base指向127.0.0.1随机端口，只调用本地夹具。非本地请求必须同时满足允许的服务商地址、allowLive与密钥；默认拒绝，不因环境中恰好有Key就自动发起收费调用。

### 按四道边界阅读

1. 调用之前检查目标与预取消，确定是否允许发请求。
2. HTTP非成功先映射错误，429保留retry-after供上层策略使用。
3. 200后检查JSON与completed状态，再提取message里的output_text。
4. 计量存在时验证数值；缺失时保持null，不能填0或用猜测补齐。

正常夹具返回“本地夹具回答”、输入12、输出5和fixture-request。数字来自夹具，不是实际token计量。

### 为什么不能只取output[0]

输出可能还包含其他类型，或没有文本。先判断条目类型和内容数组，再读取text；拒答、未完成、工具提议、空输出分别处理。本课只支持选定的文本子集，扩展新类型时要补契约。

### 带提示的练习

先让200返回null或空output，预测错误位置；再移除usage，检查“未知”是否被保留。最后做进行中取消，分别观察客户端结束与服务端资源。预取消用例不能证明正在执行的真实模型已停止计费。

## 2. 运行本地 HTTP 契约测试

### 完整实操文件：S7-L04.mjs

~~~js file=S7-L04.mjs
// 先验证允许的目标与授权，再发请求，最后校验完成状态、文本和计量。
import assert from "node:assert/strict";
import { createServer } from "node:http";
import { once } from "node:events";
// 把外部响应转换成内部结果；课堂只访问回环夹具，不发付费请求。
async function generateTextWithAdapter({
  base: baseUrl,
  model: modelName,
  input: inputText,
  signal: abortSignal,
  allowLive: allowLiveRequest = false,
  key: apiKey,
}) {
  const providerUrl = new URL(baseUrl);
  const isLocalFixture =
    providerUrl.hostname === "127.0.0.1" && providerUrl.protocol === "http:";
  if (
    !isLocalFixture &&
    !(providerUrl.origin === "https://api.openai.com" && allowLiveRequest && apiKey)
  ) {
    throw new Error("LIVE_CALL_NOT_AUTHORIZED");
  }
  const requestHeaders = { "content-type": "application/json" };
  abortSignal?.throwIfAborted();
  if (!isLocalFixture) {
    requestHeaders.authorization = "Bearer " + apiKey;
  }
  const providerResponse = await fetch(new URL("/v1/responses", providerUrl), {
    method: "POST",
    headers: requestHeaders,
    signal: abortSignal,
    body: JSON.stringify({
      model: modelName,
      input: inputText,
      max_output_tokens: 200,
    }),
  });
  if (!providerResponse.ok) {
    await providerResponse.body?.cancel();
    throw Object.assign(new Error("UPSTREAM_HTTP_" + providerResponse.status), {
      status: providerResponse.status,
      retryAfter: providerResponse.headers.get("retry-after"),
    });
  }
  const responsePayload = await providerResponse.json();
  if (
    !responsePayload ||
    responsePayload.status !== "completed" ||
    !Array.isArray(responsePayload.output)
  ) {
    throw new Error("INVALID_OR_INCOMPLETE_RESPONSE");
  }
  const outputText = responsePayload.output
    .filter((outputItem) => outputItem?.type === "message")
    .flatMap((outputItem) =>
      Array.isArray(outputItem.content) ? outputItem.content : [],
    )
    .filter(
      (outputItem) =>
        outputItem?.type === "output_text" && typeof outputItem.text === "string",
    )
    .map((outputItem) => outputItem.text)
    .join("");
  if (!outputText.trim()) {
    throw new Error("NO_TEXT_OUTPUT");
  }
  const reportedUsage = responsePayload.usage;
  if (
    reportedUsage != null &&
    (!Number.isInteger(reportedUsage.input_tokens) ||
      reportedUsage.input_tokens < 0 ||
      !Number.isInteger(reportedUsage.output_tokens) ||
      reportedUsage.output_tokens < 0)
  ) {
    throw new Error("INVALID_USAGE");
  }
  return {
    text: outputText,
    usage:
      reportedUsage == null
        ? null
        : {
            input: reportedUsage.input_tokens,
            output: reportedUsage.output_tokens,
          },
    providerRequestId: providerResponse.headers.get("x-request-id"),
    scope: isLocalFixture ? "fixture" : "live",
  };
}
const server = createServer(async (fixtureRequest, fixtureResponse) => {
  let rawRequestBody = "";
  for await (const chunk of fixtureRequest) {
    rawRequestBody += chunk;
  }
  const responsePayload = JSON.parse(rawRequestBody);
  assert.equal(fixtureRequest.url, "/v1/responses");
  assert.equal(responsePayload.max_output_tokens, 200);
  fixtureResponse.setHeader("content-type", "application/json");
  if (responsePayload.input === "rate") {
    fixtureResponse.writeHead(429, { "retry-after": "2" });
    return fixtureResponse.end('{"error":{"code":"rate_limit"}}');
  }
  if (responsePayload.input === "broken") {
    return fixtureResponse.end('{"status":"completed","output":[]}');
  }
  if (responsePayload.input === "no-usage") {
    return fixtureResponse.end(
      JSON.stringify({
        status: "completed",
        output: [
          { type: "message", content: [{ type: "output_text", text: "计量未知" }] },
        ],
      }),
    );
  }
  if (responsePayload.input === "null") {
    return fixtureResponse.end("null");
  }
  fixtureResponse.setHeader("x-request-id", "fixture-request");
  fixtureResponse.end(
    JSON.stringify({
      status: "completed",
      output: [
        { type: "message", content: [{ type: "output_text", text: "本地夹具回答" }] },
      ],
      usage: { input_tokens: 12, output_tokens: 5 },
    }),
  );
});
server.listen(0, "127.0.0.1");
await once(server, "listening");
const baseUrl = "http://127.0.0.1:" + server.address().port;
try {
  const adapterResult = await generateTextWithAdapter({
    base: baseUrl,
    model: "fixture-model",
    input: "hello",
  });
  assert.deepEqual(adapterResult, {
    text: "本地夹具回答",
    usage: { input: 12, output: 5 },
    providerRequestId: "fixture-request",
    scope: "fixture",
  });
  await assert.rejects(
    generateTextWithAdapter({ base: baseUrl, model: "fixture", input: "rate" }),
    (e) => e.status === 429 && e.retryAfter === "2",
  );
  await assert.rejects(
    generateTextWithAdapter({ base: baseUrl, model: "fixture", input: "broken" }),
    /NO_TEXT/,
  );
  const missingUsage = await generateTextWithAdapter({
    base: baseUrl,
    model: "fixture",
    input: "no-usage",
  });
  assert.equal(missingUsage.usage, null);
  await assert.rejects(
    generateTextWithAdapter({ base: baseUrl, model: "fixture", input: "null" }),
    /INVALID_OR_INCOMPLETE/,
  );
  const cancelController = new AbortController();
  cancelController.abort();
  await assert.rejects(
    generateTextWithAdapter({
      base: baseUrl,
      model: "fixture",
      input: "hello",
      signal: cancelController.signal,
    }),
  );
  await assert.rejects(
    generateTextWithAdapter({
      base: "https://api.openai.com",
      model: "unset",
      input: "hello",
    }),
    /NOT_AUTHORIZED/,
  );
  console.log("local Responses-shaped HTTP: text/usage/request-id normalized");
  console.log(
    "429 + empty output + pre-cancel + unauthorized live call rejected; live calls=0",
  );
} finally {
  await new Promise((resolve) => server.close(resolve));
}

## 3. 这份适配器还缺什么

本例为了聚焦契约，没有实现响应体大小限制、工具调用、流式事件、拒答映射、真实模型名称校验、完整错误分类和有限重试。流式接入可复用 S1-L03 的分帧思想，但必须按服务商真实事件类型解析，不能直接套用课堂自定义事件。

预取消测试不能证明进行中的真实请求已取消。你要增加等待中的本地服务器、观察断连和资源清理；真实服务即使收到取消，也可能已产生计量，需查询服务记录。

## 4. 如何做一次真实验证

在已授权服务、模型、费用上限和非敏感数据范围内，配置本地密钥，先只做少量代表性请求。记录模型标识、API/适配器版本、Prompt、输入集、请求关联、计量、延迟与错误。不要把密钥写入代码、浏览器、Git 或共享截图。

先验证协议成功，再运行业务评分。真实模型输出不应成为脆弱的固定字符串单测，而应按结构、事实与业务要求评分。模型路由变更后重跑同集，保留回归与不确定性。

本课没有执行上述付费验证。你提交时明确分开：夹具契约通过、真实服务互通、业务质量评测、生产运行。四者不能用一个“测试通过”概括。

## 故障练习与项目迁移

让200返回非法 JSON、未完成状态或拒答内容，分别设计错误映射。没有 usage 时保留 null，非法计量才拒绝，不能混淆未知与错误。让429反复出现，加入全局重试预算与退避。增加进行中取消并观察服务端清理。

项目练习：让应用只依赖内部 adapter 接口，保留 Mock 与至少一个真实适配设计。只有实际授权执行并保存证据后，才在作品集写真实模型互通或质量结论。
