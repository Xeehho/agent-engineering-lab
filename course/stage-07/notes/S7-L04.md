# S7-L04 速记

## 三个关键判断

- 先实现受控适配层：内部模型接口应表达输入、期限、取消与完成结果，再把一家服务的请求/响应映射进去。
- 保留可复现的最小实测：仅使用已经授权的服务与本机环境变量；密钥不进入仓库、网页代码、截图或日志。
- 把效果与工程分别验收：一次 API 200 证明互通的一部分，字段合法证明契约的一部分，业务效果仍需固定样本。

## 代码阅读检查

- 数据与身份来自哪里？
- 哪一步真正验证或执行了约束？
- 哪类失败会被拒绝，何时停止或恢复？
- 证据来自机制演示、Mock、真实服务还是生产？结论有多大范围？

## 本课行动

S7-T4：在授权 API 条件下补交最小实测与固定样本报告；无条件时提交可运行适配测试并明确 live_pending。
