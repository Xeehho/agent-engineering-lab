# S7-L04 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 真实接入最先需要？

- A. 先把 Mock 标签改 live
- B. 已授权服务、密钥管理与受控预算
- C. 把 Key 写进 HTML
- D. 任意调用未知接口

公开解析：B。服务授权、适配与费用边界需一起落实。

## Q2 一次真实 HTTP 200 直接证明？

- A. 该次互通观察，不能推出业务正确率
- B. 所有分类都准确
- C. 没有输出截断
- D. 工具权限正确

公开解析：A。互通、完成、契约与效果分别验证。

## Q3 没有真实调用证据时记录为？

- A. 生产已验证
- B. 真实准确率 100%
- C. usage 设零当实测
- D. live_pending / mock_only

公开解析：D。缺条件可以保留待验证，不伪造完成。
