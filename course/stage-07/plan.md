## 过关证据

- 固定分层样本、评分器校准、关键错误发布门槛
- 模型/工具/检索/状态可关联，usage 未知不填零
- 干净环境启动、迁移、限流、降级、回滚和故障演练
- 已授权真实 API 的互通/完成/契约/效果分别验证；无 Key 留 live_pending

## 交卷

按 submissions/stage-07/README.md 提交具体 commit。老师 review 后出新的概念与故障题，标准为总分 80/100，且答辩至少 20/30、项目至少 35/50、排错至少 12/20，无关键正确性缺陷。
