## 代码阅读：亲手算一次概率与容量

### 先把名词落到数字

logit 是模型给候选项的原始分数，不是已经归一化的概率。softmax 把一组分数变成正数并除以总和。temperature 是缩放分数差异的参数；本例只研究数学变化，没有真正生成一句话。

输入 [2,1,0]、温度1。先减最大值2，得到 [0,-1,-2]；取指数约为 [1,0.368,0.135]；总和约1.503；最后的概率约为 [0.665,0.245,0.090]。温度0.3时，最大项概率约0.964，分布更集中。

### 按三步读 softmax

~~~js
const scaledLogits = logits.map((value) => value / temperature);
const largestLogit = Math.max(...scaledLogits);
const exponentials = scaledLogits.map(
  (value) => Math.exp(value - largestLogit),
);
~~~

减去同一个数不会改变最终概率比例，却能降低指数溢出的风险。程序还拒绝空数组、NaN、Infinity 和非正温度，避免产生看似有结果的无效数值。真实模型的采样参数支持范围由具体服务决定，不能直接用这份函数替代服务协议。

### 容量预算与概率是两条独立逻辑

|项目|题目给定单位|累计|
|---|---|---|
|系统指令|1000|1000|
|工具描述|1800|2800|
|历史|5000|7800|
|证据|2800|10600|
|输出预留|2000|12600|

假设总容量12000，就超出600。降低 temperature 不会减少这些输入占用。你应减少、筛选或压缩上下文，核查输出预留，并使用所选模型的实际计数与限制；这里的规划单位没有证明真实 token 数。

### 带提示的练习

先手算 [0,0] 的概率；再预测给所有 logit 同时加100，结果应怎样。对于容量问题，尝试只删历史600单位，并说明压缩时哪些否定、权限和任务状态不能丢。不要用“把温度调低”回答知识缺失或授权问题。
