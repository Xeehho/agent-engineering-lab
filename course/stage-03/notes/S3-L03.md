# S3-L03 速记

## 三个关键判断

- 建立服务与用户两条信任线：确认 Server 来源、版本、维护者与可执行代码范围，同时确认当前用户能访问的具体资源。
- 绑定资源并限制输出：ticketId 本身不是权限证明，模型生成的 tenantId 也不是当前租户。
- 考虑工具描述与输出污染：工具元数据或返回内容也可能夹带诱导指令。

## 代码阅读检查

- 数据与身份来自哪里？
- 哪一步真正验证或执行了约束？
- 哪类失败会被拒绝，何时停止或恢复？
- 证据来自机制演示、Mock、真实服务还是生产？结论有多大范围？

## 本课行动

S3-T3：对 Server 实现身份绑定、租户隔离和字段最小化；提交越权、缓存串用与污染输出的拒绝证据。
