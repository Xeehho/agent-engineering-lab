# S3-L02 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 HTTP 200 可以单独证明什么？

- A. 全部工具正确
- B. 所有权限正确
- C. SDK 完全兼容
- D. 相应 HTTP 调用的状态，不能推出工具业务成功

公开解析：D。每层有自己的成功/失败契约。

## Q2 stdio 协议进程的普通诊断日志应该？

- A. 当作工具结果
- B. 写入用户 Prompt
- C. 与协议输出分离，通常写 stderr
- D. 混在 stdout 任意位置

公开解析：C。协议输出通道必须保持可解析。

## Q3 发现缓存过期最直接影响？

- A. 训练 token 数
- B. 客户端对可用工具与契约的认识
- C. 模型参数量
- D. 数据库物理容量

公开解析：B。排查应关联客户端看到的能力版本。
