# S3-L01 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 MCP 主要解决哪类问题？

- A. AI 应用与工具/上下文服务的互操作
- B. 自动替代业务权限
- C. 训练一个新模型
- D. 保证 Agent 永远答对

公开解析：A。协议互操作与应用决策能力是不同职责。

## Q2 Host 与 Client 的关系可以是？

- A. 必须各用一台服务器
- B. Client 就是模型权重
- C. Server 永远运行在浏览器
- D. Client 是 Host 内的协议组件

公开解析：D。角色不等于固定部署单元。

## Q3 看新版规范前应先记录什么？

- A. 只看教程发布日期
- B. 不需要版本
- C. 实际采用的协议修订与 SDK 版本
- D. 只记流行框架名字

公开解析：C。版本锚点帮助避免混合不兼容的行为假设。
