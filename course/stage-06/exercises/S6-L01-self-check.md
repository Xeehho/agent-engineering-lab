# S6-L01 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 引入多 Agent 前最需要什么？

- A. 先取消预算
- B. 可测的简单基线与具体瓶颈
- C. 更多角色名
- D. 更长 Prompt

公开解析：B。只有对照才能判断复杂度是否带来收益。

## Q2 可以自然并行的任务应满足？

- A. 依赖关系允许独立推进
- B. 名字不同就行
- C. 都用不同模型
- D. 共用全部可写资源

公开解析：A。并行调度不能替代数据依赖。

## Q3 子 Agent 的预算应如何处理？

- A. 无限独立额度
- B. 只统计汇总者
- C. 不算重试
- D. 纳入任务总预算与终止控制

公开解析：D。分支与重试都属于总资源消耗。
