## 项目与考核

- [01 模型应用基础](stage-01/plan.md)： 可信工单分诊接口与 React 面板；Python 契约桥接和模型选择 ADR。
- [02 工具调用与 Agent 循环](stage-02/plan.md)： 能检索、读工单、生成草稿，并受预算与确认约束的有限 Agent。
- [03 MCP 互操作与信任](stage-03/plan.md)： 一个真实可接入的本地 MCP Server 与 Client 演示。
- [04 持久状态与任务工作台](stage-04/plan.md)： 可刷新恢复、暂停确认、排队执行的持久任务系统。
- [05 RAG 与知识数据工程](stage-05/plan.md)： 带权限、版本、逐主张引用和无答案策略的知识问答。
- [06 多 Agent 与架构取舍](stage-06/plan.md)： 有基线对照的角色协作方案和保留/回退 ADR。
- [07 评测、观测与生产交付](stage-07/plan.md)： 评测回归、脱敏 trace、容量/部署方案与真实模型证据。
- [08 毕业项目与求职表达](stage-08/plan.md)： 可演示工作台、架构与 ADR、项目简历段及模拟面试。

每课的可运行 JavaScript 机制示例见 examples/course/ 的同名 .mjs。Python、真实数据库、MCP、真实模型和部署任务需学习者按要求独立实现并提交实测；网页模拟不替代实际系统。

阶段公开考试蓝图均已准备；正式概念与故障变式在交卷后生成，个人评阅和成绩不预先填写。
