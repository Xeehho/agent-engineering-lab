# 起点诊断：先凭自己的理解回答

建议10–15分钟，不计入正式考试。先不读讲义、不查资料、不让AI代答；可以说“不知道”，老师据此安排起点。每题3–6句话即可。

1. TypeScript里把模型返回值断言成TriageResult后，程序仍可能拿到哪些不符合预期的数据？你会在哪些位置验证？
2. 模型接口HTTP 200，返回文本也是合法JSON，但里面的category是other、summary为空。这次任务成功了吗？你怎么定义成功？
3. 请求超时后，哪些工作可能仍在执行？你怎样证明它真的停止了？
4. 前端调用AbortController.abort()后，你能据此证明模型服务也停止了吗？需要看哪些证据？
5. AI说“全部测试通过”，你要交付这个项目，接下来亲自核对哪些内容？
6. Prompt、工具调用、MCP这三个概念分别在你用过的Agent中承担什么作用？不确定时给出你的理解即可。

答案写在submissions/stage-01/diagnostic.md，也可以先在聊天回答。老师先标记已有能力与待核实能力，再调整学习单元长度。
