# 老师讲评与公开练习参考答案

这里保存可复用的教学理解：先判断什么、怎样从具体输入推到结论、哪里容易混淆、用什么反例验证。不是隐藏的模型思考记录，也不是关键词评分规则。

每课以原题号组织，涵盖F1–F3、原C题、FQ1–FQ2与原Q题。开放题配套参考回答、推导与反例、自查要点；选择题补充判断依据和选项误区。题目、当前选项及正确选择由构建器从课程元数据加入下载版，避免手工维护两套题面。

网页随堂练习可以展开参考答案，并下载本课完整讲评Markdown。建议先思考再对照；查看答案不会替你填写作答、增加自测分数或认证掌握。开放题允许不同的合理实现，应检查机制、边界与证据，不能要求逐字复述。

这是项目所有者要求公开的学习资料，许可CC BY 4.0。正式阶段考试仍在真实交卷后生成新变式；阶段项目实现与个人成绩不会因参考资料完整而自动完成。

编辑对应课号Markdown后运行classroom:build和check。加载器检查题号覆盖、重复与遗漏；技术事实仍应对照讲义中的官方来源。新题或语义变化必须同时复核讲评，不能只满足字数检查。
