# S2-L02 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## FQ1 Agent循环为什么需要再次决定？

- A. 根据刚执行取得的结果选下一步
- B. 无限重复同一句问题
- C. 让模型绕过应用授权
- D. 保证每轮都发送一封邮件

公开解析：A。中间结果改变可用信息，程序仍控制允许操作与停止。

## FQ2 本课第一次查一次文档后第二轮结束，实际有几次工具执行？

- A. 2次
- B. 3次
- C. 无法区分轮次和工具数
- D. 1次

公开解析：D。两轮决定不等于两次工具调用；第二轮直接返回final。

## Q1 循环预算必须由谁落实？

- A. 程序在执行边界强制限制
- B. Prompt 自行保证
- C. 用户的主观感觉
- D. UI 动画

公开解析：A。自然语言限制不能替代执行控制。

## Q2 三轮模型调用能保证最多三个工具吗？

- A. 能，所有协议都规定一轮一个
- B. 只有 React 能保证
- C. 不需要计算
- D. 不能，一轮可能提出多个工具调用

公开解析：D。区分模型轮次与工具执行次数。

## Q3 业务路径确定时首先建立什么？

- A. 无限上下文
- B. 无记录自动重试
- C. 简单可测的确定性流程基线
- D. 最多的 Agent 角色

公开解析：C。复杂度是否值得，要通过对照验证。
