# S4-L01 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 长任务应该以什么作为主要业务标识？

- A. 只用浏览器连接编号
- B. 只用 loading 布尔值
- C. 用模型生成的摘要
- D. 独立 taskId，保留各次 request/attempt 关联

公开解析：D。业务任务生命周期可以长于一次 HTTP 请求。

## Q2 恢复前最关键的检查之一是？

- A. 默认所有工具没执行
- B. 生成新幂等键重来
- C. 已完成副作用和下一步是否能重复执行
- D. 把历史全部重新播放

公开解析：C。恢复需保留执行边界与幂等结果。

## Q3 数据库事务能自动回滚第三方 API 吗？

- A. 页面取消会自动回滚
- B. 不能，需要额外幂等/补偿/对账设计
- C. 所有 HTTP 都能回滚
- D. 只要有 TS 类型就能

公开解析：B。事务边界通常不跨独立外部服务。
