# S6-L02 交接不能只说“我查过了”

## 先说我们要解决什么问题

研究角色把“应该能退款”交给写作角色。如果不带来源、版本和不确定项，后者无法核实，却可能把猜测写成确定结论。

## 先把概念讲清楚

交接契约规定一个角色把什么可检查的信息交给下一个角色。证据包应携带任务身份、资料来源与版本、已经验证的事实、未解决问题、权限和副作用状态。它不是模型隐藏思考过程的转发；应记录可审核的外部依据和决策摘要。

遇到冲突先定位来源和规则，再决定追问、重新检索或交给人。不要让两个角色互相说服到无限循环；总轮数、时间和费用仍由应用限制。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|packet / taskId|课堂证据包与任务编号|
|sourceVersion / unresolved|资料版本与未解决事项；课堂约定|
|expectedVersion|接收方要求的当前版本，来自可信任务记录|
|accept|课堂接收检查；真实交接还需结构、权限和来源验证|
