# S4-L01 任务状态是可检查的记录

## 先说我们要解决什么问题

生成报告需要一分钟。用户刷新页面以后，不能只剩一个永远转动的加载图标。服务端怎样告诉界面：任务还在跑、失败了，还是已经结束？

## 先把概念讲清楚

任务是应用保存的一次工作记录，状态是它当前所处的位置。状态机就是明确列出允许的状态变化，例如queued→running→succeeded；已经成功的任务不能被晚到消息改回running。持久化表示把记录写到进程退出后仍能读回的存储。

先用内存对象看变化规则。request是一回请求，task是可跨请求查询的工作，attempt是某次执行尝试；一次任务重试会有多个attempt，不能混成同一个编号。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|task / state / version|本课任务对象、状态与修改版本；非模型字段|
|queued / running / succeeded / failed|本课业务状态词，不是通用数据库状态|
|allowed|本课允许变化表|
|transition|本课执行条件检查的函数；真实项目放在原子数据库更新中|
