# S8-L03 简历能力要能指向具体证据

## 先说我们要解决什么问题

简历写“精通Agent、RAG、MCP”，面试官问一次失败复盘，你却只能展示AI生成的代码。怎样把项目经验写得准确又有说服力？

## 先把概念讲清楚

能力陈述应包含你解决的具体问题、承担的判断、实现机制、验证方法和边界。AI协助写代码可以如实说明，重点展示你怎样定义正确结果、审查生成代码、定位错误和承担设计取舍。课程完成不保证职位或薪资，就业还取决于实际能力、项目、表达和岗位匹配。

公开作品避免提交密钥、个人工单、真实用户记录或未授权资料。岗位索引只作为历史需求样本，求职前要重新核对在招状态与要求。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|claim / artifact / scope|课堂能力陈述、证据链接与验证范围|
|reviewed|课堂是否有人核查的标记，不是正式成绩|
|ready|本例清单完整判断，不能自动认证能力或就业水平|
|Boolean|JavaScript布尔转换，只判断有没有填写|

## 运行结果与逐步解释

~~~text
陈述材料齐备： true 已评阅： false
~~~

三项非空所以清单齐备，但reviewed仍false。填上字符串不等于具备能力，链接应能打开，测试应能复现，解释应经得起追问。正式阶段通过只能在真实交卷与评阅后记录，不能因为网页进度达到100%自动填写。
