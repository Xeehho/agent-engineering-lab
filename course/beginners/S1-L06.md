## 先说我们要解决什么问题

前端给 /triage 发 JSON，后端返回分组。你不熟 Python，怎样读懂这条链路，而不是先把语言语法书从头背一遍？

## 先把概念讲清楚

后端服务在这里做三件事：接收 HTTP 请求、验证输入、调用业务函数并返回结果。路由是把“请求方法+路径”映射到处理函数的规则；框架是替你处理协议细节的工具库。Python 的 def 类似 JS 函数声明，dict 类似普通对象，async def 表示可异步等待的函数，并不自动把阻塞计算移出线程。

网页先用熟悉的 JavaScript 观察边界。进阶代码使用 Python、FastAPI 和验证模型，语法不同，但输入输出责任相同。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|body|HTTP请求体解析后的课堂对象；不是可信身份|
|status / json|课堂模拟响应字段，不是原生 Response 实例|
|handle|课堂模拟路由函数；FastAPI 实际用装饰器登记路由|
|400 / 200|HTTP标准状态码；本例演示校验失败/成功；真实框架可能用422表示校验失败|
