# S1-L02 停止等待和停止工作是两件事

## 先说我们要解决什么问题

用户点了取消，界面不转圈了，但后台还在生成并扣费。取消按钮到底取消了什么？

## 先把概念讲清楚

超时是到规定时间不再继续等，取消是主动请求停止。JavaScript 的 Promise 表示一个以后才得到结果的操作；Promise.race 只选择最先完成的结果，不会自动停止另一个操作。AbortController 是 Web 标准中的取消通知器，它发出的 signal 只有被执行方监听并配合处理，才能中止相应工作。

我们先不加定时器，直接在操作开始前发取消信号，观察协作关系；进阶再处理执行中取消和晚到返回。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|controller / signal|Web 标准对象与取消信号，名称由标准规定|
|run / calls|本课函数与计数变量，记录是否开始工作|
|aborted|signal 上的标准布尔属性；表示已请求取消|
|cancelled / done|课堂返回文字，不是服务商状态码|

## 运行结果与逐步解释

~~~text
cancelled
实际开始次数： 0
~~~

创建通知器时尚未取消。abort 让 signal.aborted 变成 true。run 读到 true 就提前返回，calls 仍是 0。如果删掉检查，通知器仍显示取消，但工作会开始。对真实模型服务，还要确认 SDK/HTTP 传输是否接受 signal，以及远端能否停止。
