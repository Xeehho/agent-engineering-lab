# S5-L03 有引用链接，不等于引用支持答案

## 先说我们要解决什么问题

模型回答“退款三天到账”，后面附了一份真的退款文档。但文档实际说“审核需要三天”。链接是真的，结论仍然可能错。

## 先把概念讲清楚

召回是先找一批候选，重排是再按当前问题对候选排序。生成答案时，应把答案拆成可以单独核验的主张，再核对每条是否得到资料支持。引用只是把主张指回来源的连接，不能自动证明内容蕴含关系。

拒答或追问是资料不足时的正常结果。过期、冲突、无权限和根本没资料是不同原因，应给出适当解释，不要统一编造一个流畅答案。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|claim / evidenceId|课堂主张文字与引用编号|
|facts|课堂人工标注的支持关系，不是模型自动裁判|
|supported|课堂精确匹配结果；现实需要语义与上下文核验|
|every / find|JavaScript查找检查方法，不是检索服务接口|

## 运行结果与逐步解释

~~~text
引用存在： true 主张受支持： false
资料不足，不能确定到账时间
~~~

find找到了doc-1，只说明引用编号存在。比较人工标注主张后发现不同，于是拒绝断言到账时间。本例用严格字符串匹配便于理解，会错拒同义表达；真实评测需人工校准或受控裁判，不能把字符串不等直接当语义不支持。
