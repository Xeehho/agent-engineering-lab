# S1-L01 先分清：收到回答与完成业务

## 先说我们要解决什么问题

客服想把一条工单分到技术支持组。模型返回了一个字符串，但字符串也许不是 JSON，里面也许写了不存在的组。我们怎样判断这次工作能不能交给下一步？

## 先把概念讲清楚

模型应用是把模型放进普通软件中的应用。模型生成候选内容，程序决定候选能否使用。这里有四道不同的检查：请求有没有拿到返回；文本能不能解析；字段类型对不对；内容是否符合当前业务。HTTP 200 只说明传输层返回成功，不能代替后三道检查。

JSON 是一种用文本表达对象、数组、数字等数据的格式。JSON.parse 把文本变成 JavaScript 值；它不会替你判断业务真假。契约就是应用事先约定“接受什么输入、输出必须长什么样、什么条件算成功”。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|raw|模型返回的原始文本；课堂变量|
|group|分配组；本课业务字段，只允许技术支持或账务支持|
|parse|本课函数；先解析再检查，不是模型 API|
|JSON.parse / typeof|JavaScript 标准能力；分别负责解析和检查类型|
