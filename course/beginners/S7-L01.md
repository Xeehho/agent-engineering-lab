# S7-L01 先约定什么错误会阻止发布

## 先说我们要解决什么问题

你改了Prompt，十道题里九道更好，一道把A公司的资料发给B。总分90看起来不错，但这样的版本能发布吗？

## 先把概念讲清楚

评测集是一组有固定输入和评分依据的案例。评分器把实际输出与依据比较，可以是确定规则、人工评阅或经过校准的模型裁判。回归是新版本在原来能做好的案例上退步。发布门槛应提前定义，关键越权或重复扣款不能被平均分抵消。

评测不是正式学习考试：本课公开练习帮助理解工程质量，学习者阶段考试仍由老师在交卷后给新变式。真实应用评测需要记录模型、Prompt、工具、数据和评分器版本。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|cases / passed / critical|课堂案例与通过标记、是否关键项|
|accuracy|本例案例通过比例，不是所有任务的通用质量指标|
|release|课堂发布判断；实际发布还需安全和运行条件|
|some / every|JavaScript检查方法；关键项规则由业务事先规定|
