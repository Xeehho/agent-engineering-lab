# S5-L01 RAG 先从一份能追溯的文档开始

## 先说我们要解决什么问题

助手要回答公司的报销制度。直接让模型凭记忆回答容易引用旧规定；把文档复制成很多小段后，又可能忘记每段属于哪家公司、哪一版。

## 先把概念讲清楚

RAG是Retrieval-Augmented Generation，意思是先检索外部资料，再把资料交给模型辅助生成。它通常不修改模型权重。检索前要做知识入库：获取原文、清理、切分、标记来源与版本、建立索引。chunk就是切分出来的一段资料。

切分不是随意每100字剪一次：标题、段落、表格和前后条件会影响意义。下面先用两个完整段落练来源标记。权限过滤必须先于向用户或模型暴露内容，不能等答案生成后再遮盖。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|document / version / tenant|课堂原文及版本、租户字段，来自受控业务存储|
|chunkId / sourceId / text|课堂片段编号、原文编号、片段内容|
|active|课堂可用标记；删除还要清理索引和缓存|
|split|JavaScript拆分文本方法，不是智能文档解析器|
