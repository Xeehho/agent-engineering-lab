# S7-L04 把服务商响应转换成应用自己的结果

## 先说我们要解决什么问题

应用里的循环希望拿到type=final或tools，但真实模型服务可能用不同字段表示文本、工具、拒绝和截断。直接把外部对象散落到业务代码，会让换服务或升级接口很困难。

## 先把概念讲清楚

适配器负责把外部接口转换成应用内部契约。先读采用的服务商与SDK版本文档，分清返回成功、内容完整、工具提议、拒绝和用量未知等情况。结构化输出可帮助约束形状，仍不能证明业务内容正确。

真实接入是需要授权凭证与可能产生费用的进阶验证。本网页不请求任何模型。下面故意采用自定义fakeProvider格式，避免把课堂字段误认成某家SDK标准。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|fakeProvider / outputText / stop|本课人为构造的外部格式，不属于任何服务商API|
|type / text|本课应用内部结果格式，供S2-L02循环读取|
|normalize|课堂适配函数，将外部终态映射成内部结果|
|truncated|本课截断标签，不是服务商通用字段值|
