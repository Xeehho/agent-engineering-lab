# S1-L05 模型看到的输入并不等于全部历史

## 先说我们要解决什么问题

你把十万字文档和整段聊天都发给模型，结果费用上涨，关键限制仍被忽略。模型到底能接收多少信息？

## 先把概念讲清楚

大语言模型根据输入中的符号序列生成后续内容。Token 是模型分词器使用的单位，可能是一段字、一部分词或标点；不能固定理解成“一个汉字”。上下文窗口是一次请求能容纳的输入和输出等 token 总量上限，具体计数随服务而异。

上下文工程就是选择这次真正需要的规则、任务和证据，并安排其来源、预算和顺序。它不意味着把所有资料都塞进去。下面用教学计数代替真实分词，只练预算算术。

## 名字与字段从哪里来

|名字或字段|来源与含义|
|---|---|
|capacity / outputReserve|课堂变量：示例窗口容量与预留输出量|
|tokens|预先给定的教学估计值，不是真实分词结果|
|selected / used|应用挑中的片段及已占用量|
|filter / push|JavaScript 数组方法；不是模型的记忆 API|
