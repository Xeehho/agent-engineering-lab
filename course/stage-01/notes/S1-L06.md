# S1-L06 速记

## 三个关键判断

- 对照两种语言的边界：重点迁移 dict/list、函数与异常、类型提示、包与虚拟环境。
- 辨认异步与阻塞操作：async 是协作式并发的接口表达，不会把任意阻塞 I/O 或 CPU 计算自动变快。
- 做一条可验证的最小迁移：迁移目标是保留契约、错误码和取消语义，而不是逐行翻译语法。

## 代码阅读检查

- 数据与身份来自哪里？
- 哪一步真正验证或执行了约束？
- 哪类失败会被拒绝，何时停止或恢复？
- 证据来自机制演示、Mock、真实服务还是生产？结论有多大范围？

## 本课行动

Python 桥接作业：在独立目录用虚拟环境实现 health/validate，保留 TS 主线；提交真实运行证据及两种实现的契约对照。
