## 1. 对照两种语言的边界

重点迁移 dict/list、函数与异常、类型提示、包与虚拟环境。Python 类型提示本身也不是所有外部 JSON 的运行时校验器。读取接口时先找路由、请求模型、依赖与返回契约，再读实现。不要因为类型注解看起来正确，就跳过真实数据验证。

## 2. 辨认异步与阻塞操作

async 是协作式并发的接口表达，不会把任意阻塞 I/O 或 CPU 计算自动变快。阅读 FastAPI 文档了解普通 def 与 async def 的执行方式，并检查所用数据库/HTTP 库是否支持异步。同步阻塞操作放错位置会影响同一事件循环里的其他任务，需按库和工作负载处理。

## 3. 做一条可验证的最小迁移

迁移目标是保留契约、错误码和取消语义，而不是逐行翻译语法。先在本机虚拟环境中实现 health 与一个校验接口，再让 React 调用。安装版本需锁定并写可复现步骤。网页实验仅演示队列顺序；Python 实际服务必须在本地环境单独运行和验证。

## 实验：await 表达的是等待点

先预测输出，再运行并修改一个条件。这是教学用的 JavaScript 机制演示，不是真实模型、数据库、协议 SDK 或生产系统。

~~~js
const events = [];
async function handle(name) {
  events.push(name + ":start");
  await Promise.resolve();
  events.push(name + ":resume");
}
await Promise.all([handle("A"),handle("B")]);
console.log(events);
~~~

观察方向：先出现两个 start，再出现两个 resume；这不是 Python 运行，也没有 CPU 并行。

提示：区分任务可交错推进和同时使用多个 CPU 核心。
