# S1-L03 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 网络 chunk 与业务事件的关系是？

- A. 需要按协议缓存与分帧
- B. 总是一对一
- C. chunk 必然是完整 JSON
- D. 一个中文字符绝不跨 chunk

公开解析：A。传输边界不等于消息边界。

## Q2 任务取消后收到同一任务的旧 delta，应当？

- A. 显示成功
- B. 清空所有其他任务
- C. 重新开始计费调用
- D. 按状态与标识拒绝更新

公开解析：D。终态和关联标识用于阻止状态被晚到事件破坏。

## Q3 HTTP 头已发出后遇到失败，主要依靠？

- A. 把已有输出当完整结果
- B. 只关闭 loading
- C. 协议内错误终止事件与日志
- D. 再发送一套状态行

公开解析：C。需提前定义流内错误与终止契约。
