# S1-L06 公开自测与解析

这是公开练习，不是正式考试。HTML 默认在提交后显示解析；此文件公开保留课程内容。

## Q1 Python 类型提示能独立保证外部 JSON 合法吗？

- A. 有 async 就能
- B. 不能，需要实际运行的验证
- C. 任何情况下都能
- D. 只有字符串自动验证

公开解析：B。类型提示与运行时契约应分开检查。

## Q2 async 关键字意味着？

- A. 函数可参与异步协作，但仍需避免阻塞
- B. 自动启用多个 CPU
- C. 所有库都变异步
- D. 不再需要超时

公开解析：A。并发、并行、阻塞 I/O 是不同概念。

## Q3 迁移服务首先要保持什么？

- A. 变量名字完全相同
- B. 代码行数一致
- C. 把所有函数改成 async
- D. 对调用方可观察的契约与错误语义

公开解析：D。先定义可观察行为，再实现并验证等价性。
