## 应用工程与后续深化

主线使用 React / TypeScript，另有 Python / FastAPI 桥接练习。数据库、队列和容器需在项目中实际使用与验证，浏览器数组/Map 只能教机制，不能代替真实服务。

目前覆盖基础机制、工程实现与求职作品训练。模型训练、分布式训练、CUDA、深入模型推理优化、Go 平台研发、多模态音视频与特定行业知识属于后续方向；按真实目标 JD 选择，不宣称本课程已提供这些方向的完整训练。

## 建议投入与学习顺序

共 31 课，每课阅读/实验约 35–60 分钟，项目训练按证据推进。八阶段整体建议预留约 90–150 小时，属于本课程安排估计，不是达到就业标准的保证。已有能力可直接交证据申请答辩。

按 01→02→03→04→05→06→07→08 推进；07 的评测、观测可提前交叉学习。所有资料现在都可阅读，个人考试按实际提交安排。材料开发速度与学习者进度互不阻塞。

每课：阅读并解释 → 先预测再运行 → 修改一个条件看反例 → 开放题 → 自测 → 项目增量。AI 可以辅助实现；你要亲自运行、阅读和解释。概念答辩要求本人作答。

## 求职准备的完成条件

- 能从干净环境复现毕业项目，并演示一个正常路径和至少三个失败/恢复路径。
- 能追踪模型、检索、工具、状态、UI 与权限，说明每个边界的责任。
- 有真实模型互通与效果证据；暂缺授权时保持待验证，不把 Mock 当模型能力。
- 有可审阅的源代码、测试、ADR、评测和脱敏演示，个人贡献与 AI 协助范围明确。
- 面对新需求和陌生故障能够提出假设、找证据、最小修复并回归。
- 简历和项目讲解不夸大经历、数据或业务效果；针对当前 JD 继续补差距。

既有岗位样本采用“北京、公布月薪下限不低于30k”的历史初筛口径，用于需求分析练习。课程帮助准备能力与证据，招聘结果仍取决于实际表现、岗位匹配和招聘过程；其他学习者应按目标地区、层级与完整JD调整。样本不是20份完整JD的逐项证明，也不代表当前仍在招。
